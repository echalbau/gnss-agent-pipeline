GNSS processing pipeline

Drop a RINEX observation file. The pipeline checks the data, fetches IGS orbits, clocks and antenna calibrations, solves the position with RTKLIB and writes a PDF report.

  1. Check RINEX quality

    Header, epochs, gaps and frequencies

  2. Fetch IGS products

    Orbits, clocks and antenna calibrations, with mirror fallback

  3. Solve position

    RTKLIB precise point positioning or RTK

  4. Evaluate precision

    Retunes the filter and solves again if criteria are not met

  5. Write report

    Coordinates, precision and a written summary
